# Rennrad Hoamat

Karte für verkehrsscheue Rennradfahrer in Bayern, Baden-Württemberg, Tirol und Südtirol.
Sie färbt asphaltierte Wege nach Verkehrsaufkommen ein (OpenStreetMap und amtliche Verkehrszählungen),
zeigt eigene und geladene GPX-Tracks und markiert mit dem Track-Check Abschnitte abseits geeigneter Wege.

**Öffnen und installieren:** https://walterhansi.github.io/rennrad-hoamat/
In Chrome erscheint rechts in der Adresszeile das Symbol „App installieren“.

## Daten
- Wegdaten © OpenStreetMap-Mitwirkende (ODbL)
- Verkehrsmengen: Bayerische Straßenbauverwaltung – BAYSIS (CC BY 4.0); Verkehrsministerium Baden-Württemberg über MobiData BW (dl-de/by-2-0); ASTAT und Autonome Provinz Bozen (CC0)
- Grundkarten: basemap.de / BKG, basemap.at (CC BY 4.0), Autonome Provinz Bozen (CC0), Esri
- Routing: BRouter
